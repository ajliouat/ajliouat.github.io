Problem and scope

A successful plan is only useful if the robot can execute it. RoboLLM separates instruction parsing, object grounding and motor control so each component can be inspected independently. Its existing mock backend makes integration tests inexpensive; it does not measure a vision-language model’s understanding of a camera image.

Implemented and experimental components

  • Environment: a Franka-inspired seven-joint arm in MuJoCo with a tabletop, randomized objects and bounded episodes.
  • Tested planning path: MockVLM performs keyword matching; SimGrounder reads privileged simulator state. Passing these tests is not visual grounding accuracy.
  • Motor control: scripted controllers support pipeline tests. SAC training and checkpoint evaluation are separate components; successful learned manipulation is not established by the baseline archive.
  • Extension points: a Transformers VLM adapter exists. DINOv2-based visual grounding remains a proposed extension in the reviewed source.

Grounded control study · 26 September 2026

The executor could select the requested object but drive toward the first object in the scene. The repair retains the named target through control and scoring, distinguishes already-satisfied states, and stops on failures or episode endings.

Measured result: zero successes in 100 scenes for the corrected controller, and zero for each of three controls. The corrected controller ended 33.13 cm from the target on average, against a 3 cm threshold. The targeting defect is fixed; successful motor control remains unresolved.

The frozen study retains 400 complete episode traces and an exact local replay. It uses privileged simulator state and scripted actions, with no learned policy or VLM evaluation. Read the failure, method, results and limits · Inspect the raw evidence.

Focused GitHub validation passed 180 tests and a simulation smoke. This is a review-branch delivery, not a main-branch merge or a pass of the repository’s full training/rendering suite.

Language-task success checks final scene predicates, which can already hold at reset; 4/100 does not demonstrate language understanding. The other archived random baselines—color pick, stacking and sorting—each report 0/100 successes. A dash or an absent run is not a zero result. Less-negative shaped return does not imply a multiplicative improvement or successful manipulation.

The original archive does not contain per-episode traces or complete environment/version provenance, and the evaluator did not seed the random action space. These records establish what was reported, not an exactly reproducible run or a learned-policy benchmark.

Reproduction and next investigation

The frozen protocol and reproduction guide define the 100 paired scenes, four controls, recorded runtime and exact success condition. The new experiment exercises three-object reaching; it is not directly comparable to the historical one-object baseline.

Next: isolate arm, actuation and inverse-kinematics behavior on a separate development set before tuning or training. Reaching, grasping, stable placement and language understanding each require their own evidence.
